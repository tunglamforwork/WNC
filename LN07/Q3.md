## Question 3
Students describe the differences between synchronous api call and asynchronous api call

### Cách hoạt động:
Synchronous: Chương trình chờ API trả kết quả, rồi mới chạy tiếp.

👉 Ví dụ: Đứng chờ nấu xong cơm rồi mới ăn.

Asynchronous: Chương trình không chờ, tiếp tục làm việc khác, kết quả API sẽ xử lý sau.

👉 Ví dụ: Cắm cơm, rồi đi làm việc khác trong lúc cơm chín.

### Hiệu suất:
Synchronous: Phù hợp với tác vụ đơn giản, nhưng dễ bị chậm nếu API lâu trả kết quả.

Asynchronous: Làm việc hiệu quả hơn khi cần xử lý nhiều tác vụ cùng lúc.

### Thích hợp dùng khi:
Synchronous: Khi cần kết quả ngay lập tức để làm tiếp (ví dụ: đăng nhập).

Asynchronous: Khi xử lý nhiều việc cùng lúc hoặc chờ lâu (ví dụ: tải nhiều dữ liệu).

### Hiểu đơn giản:
Synchronous: Làm xong việc này mới làm việc khác.

Asynchronous: Làm nhiều việc cùng lúc, không chờ.
